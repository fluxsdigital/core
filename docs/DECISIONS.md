# Decisões

| ID      | Decisão                                                  | Motivo                                                                                                                                                                                                                                  |
| ------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ADR-001 | Adotar um monólito modular para a API                    | Separar domínios no código e manter transações no mesmo PostgreSQL.                                                                                                                                                                     |
| ADR-002 | Usar PostgreSQL 17, Prisma 6 e migrações versionadas     | A equipe pode reproduzir o esquema e revisar mudanças em SQL.                                                                                                                                                                           |
| ADR-003 | Compartilhar UI no workspace                             | Os aplicativos e futuras extensões reutilizam componentes e tokens de design.                                                                                                                                                           |
| ADR-004 | Configurar loopback no desenvolvimento                   | API, frontend e banco de desenvolvimento ficam acessíveis na máquina local.                                                                                                                                                             |
| ADR-005 | Usar cookies HttpOnly e refresh opaco rotativo           | O JavaScript da interface não lê credenciais de sessão. A API guarda o hash do refresh e consulta o estado revogável da sessão.                                                                                                         |
| ADR-006 | Associar membros pelo identificador da conta             | A empresa vincula uma conta específica sem depender da verificação de endereço de e-mail.                                                                                                                                               |
| ADR-007 | Fixar nomes e preços nos itens do orçamento              | A emissão mantém os valores registrados mesmo após alterações no catálogo.                                                                                                                                                              |
| ADR-008 | Limitar cada orçamento aprovado a uma ordem              | Uma restrição única em PostgreSQL e a recuperação da ordem existente tornam a operação repetível.                                                                                                                                       |
| ADR-009 | Aplicar módulos e identidade por empresa                 | A API lê a configuração junto da associação do usuário. A interface usa a mesma configuração para compor a experiência.                                                                                                                 |
| ADR-010 | Preparar extensões por domínio com escopo da empresa     | Campos adicionais e integrações compartilham os IDs compostos e o contexto de permissão do núcleo. O guia define onde implementá-los.                                                                                                   |
| ADR-011 | Homologar com Nginx/TLS e publicação em loopback         | Permite avaliação privada e fornece uma origem única para web e API.                                                                                                                                                                    |
| ADR-012 | Aplicar versões transitivas corrigidas na CLI do Prisma  | Os overrides são restritos a `@prisma/config` e foram validados com geração, migração e testes. Avisos [deepmerge-ts](https://github.com/advisories/GHSA-ggr8-5vv4-36mx) e [effect](https://github.com/advisories/GHSA-7589-6fvf-x4pw). |
| ADR-013 | Atualizar dependências transitivas do ambiente de testes | Os overrides corrigem os avisos [glob](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4) e [minimatch](https://github.com/advisories/GHSA-g3hv-75wg-m249).                                                                             |
